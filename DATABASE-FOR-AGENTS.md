1. Statement timeout at a role level
    Create an `agent_worker` and define apt timeouts
    ```
    CREATE ROLE agent_worker;
    ALTER ROLE agent_worker SET statement_timeout = '5s';
    ALTER ROLE agent_worker SET idle_in_transaction_session_timeout = '10s';
    ```

2. Soft Deletes everything with a reason
    Never let your agents hard delete anything (even via an API/MCP)
    ```
    ALTER TABLE orders ADD COLUMN deleted_at TIMESTAMPTZ;
    ALTER TABLE orders ADD COLUMN deleted_by TEXT;
    -- 'agent: customer-support-v2'
    ALTER TABLE orders ADD COLUMN delete_reason TEXT;
    ```

3. Append only Event Logs
    For high stake writes (financial, user state), over API,MCP do no UPDATE no DELETE -- only INSERT with new state and reason
    Such that UNDO becomes a projection query
    ```
        CREATE TABLE order_state_log (
        id                           UUID DEFAULT gen_random_uuid() PRIMARY KEY,
        order_id                     UUID NOT NULL REFERENCES orders (id).
        previous_status              TEXT,
        new_status                   TEXT NOT NULL,
        changed_by                   TEXT NOT NULL, -- agent identity
        changed_at                   TIMESTAMPTZ DEFAULT now,
        reason                       TEXT,
        idempotency_key              TEXT UNIQUE        -- deduplicates retries       
        ) ;
    ```
    Basically making the DB an append only event and apply the changes after a review/approval

4. Idempotency Keys are not Optional as agents will keep on retrying and just having a unique key wont solve the issue
    ```
    def make_idempotency_key(task_id: str, step_index: int,
                             plan_hash: str, target_id: str) -> str:
        # Include plan_hash: if the agent changes its mind,
        # it is a different logical operation.
        raw = f"{task_id}: {step_index}: {plan_hash}:{target_id}"
        return hashlib.sha256(raw. encode()). hexdigest()[:32]
    ```

6. Have a dedicated connection pooling config for your agents - Connections are brief
    Because one agent might spawn out to 5 different sub agents to query or do some task
        N concurrent requests which might be 10N at prod with higher traffic
    ```
        agent_engine = create_engine(
        DATABASE_URL,
        poo1_size=10,               # base pool for agents
        max_overflow=5              # burst capacity
        pool_timeout-3,             # fail fast, not queue -- prevents cascading failure
        pool_recycle=300,           # recycle every 5 min
        pool_pre_ping=True,         # validate before checkout
        connect_args={
            "options": "-c statement_timeout=5000 -c idle_in_transaction_session_timeout=10000"
        }
    ```

7. Never Hold transaction during "Thinking"
    ```
        # BAD: Holding a lock during LLM inference
        with db.transaction():
            data = db.query("SELECT * FROM inventory FOR UPDATE*)
            decision = 11m.ask(f"Should we restock? {data}") # 10s wait
            db. execute (f"UPDATE inventory SET ...")
            
        # GOOD: Atomic operations with idempotency
        data = db.tjuery("SELECT * FROM inventory")
        decision = l1m.ask(f"Should we restock? {data}")
        with db.transaction():
            db.execute ("UPDATE inventory SET ... WHERE version = ;v", {"v": data. version})
    ```

8. Bad queries fail loudly
    Lets say we want to run a filter query on DB and it got no response maybe the query it fired was bad as it hallucinated and the agent thought actually there was no result found
    Tag every Agent Query - we need to log or add comments to SQL query when generated by agents with reasoning step. Comments surface in `pg_stat_activity` or `pg_stat_statements`
    ```
    @event.listens_for(Engine, "before_cursor_execute")
    def add_agent_context_comment(conn, cursor, statement,
                                  parameters, context, executemany) :
        agent_ctx = getattr(conn.info, "agent_context", None)
        if agent_ctx:
            statement = (
                f"/* agent_id={agent_ctx['agent_id']}, "
                f"task_id={agent_ctx[' task_id']}. "
                I"step={agent_ctx['step']} */ {statement}"
            )
        return statement, parameters
```
